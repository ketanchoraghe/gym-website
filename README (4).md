
# Gym Website 🏋️‍♂️

This is a modern, responsive Gym Website built using React.js and Vite. 
It showcases gym programs, trainers, membership offers, and is optimized for both desktop and mobile users. 
The project highlights smooth scrolling, interactive design, and fast performance.


## Features

- Home Page with Hero Section
- Smooth Navigation (React-Scroll)
- Programs, About, Offers, and Testimonials Sections
- Fully Responsive Design (Desktop, Tablet, Mobile)
- Fast loading with Vite build
- Live Deployed on GitHub Pages


## Installation

1. Clone the repository:
   git clone https://github.com/ketanchoraghe/gym-website.git

2. Navigate to the project directory:
   cd gym-website

3. Install the dependencies:
   npm install

4. Start the development server:
   npm run dev

5. Build for production:
   npm run build

    
## Uses

- Explore the Homepage and navigate to different sections.
- View Programs, Offers, and Testimonials.
- Experience smooth scrolling and responsive design on all devices.


## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- HTML5 + CSS3
- React-Scroll (for smooth navigation)
- GitHub Pages (for deployment)


## Deployment

This project is deployed live on GitHub Pages.

Access it here:
👉 https://ketanchoraghe.github.io/gym-website/

For deployment:
- Install gh-pages if not installed: npm install gh-pages --save-dev
- Update package.json with homepage field
- Run npm run build
- Deploy using: npm run deploy
